隐私政策

更新及生效日期 2026 年 11 月 4 日

本政策适用于 GRemote App 和 GRemote 官网。GRemote 无需注册账号。相机控制、相册整理和照片编辑在手机与相机之间或在手机本地完成。GRemote 不会将你的照片、取景画面或机内设置上传到开发者服务器。

App 如何使用权限和数据

  • 相册与文件。在你授权或选择文件后，App 会读取照片及所需的元数据，用于浏览、显示、编辑与导出，也可按你选择读取 LUT 或胶卷文件。编辑结果可另存为新副本。使用系统分享功能时，内容会交给你选定的接收方。
  • 蓝牙、附近设备和本地网络。用于发现和连接兼容相机、读取连接信息、实时取景、遥控拍摄与传输照片。启用 M10V 联动时，App 通过相机 Wi-Fi 与相机交换配对信息、胶卷和扩展设置。配对信息按连接方式保存在会话中或设备本地。
  • 位置。在你开启拍摄位置记录并授予权限后，App 在联机拍摄且处于前台时使用位置为拍摄记录匹配地点。位置记录保存在本机；按导出设置，位置也可能写入导出的照片。你可在 App 或系统设置中关闭位置访问。
  • 胶卷库更新。App 会向 M10V 网站请求胶卷目录及所需的图标或 LUT。此类下载会让网站接收到普通网络请求信息，例如 IP 地址。App 不会随这些请求发送照片、位置记录或相机配对信息。

网站访问与主动反馈

官网不要求登录，也不在页面中植入广告跟踪脚本。网站服务器会生成常规访问日志，可能包括 IP 地址、访问时间、请求路径和浏览器信息，用于维护、安全和故障排查，按服务端日志轮转设置保留。访问 GitHub、M10V 官网等外部链接后，相应服务按其各自的隐私规则处理请求。

如果你主动发送邮件或提交 GitHub 问题，我们会使用你提供的联系方式、描述或附件来处理反馈。GitHub 问题可能公开显示。涉及隐私的请求请通过邮件发送，避免在公开问题中附上个人照片、位置或配对文件。

管理、撤回与删除

你可以在系统设置中撤回相册、位置、蓝牙或本地网络等权限。应用内保存的草稿、偏好和缓存由设备保存，可通过相应的应用功能或系统存储设置清理。已保存至系统相册、导出至文件或写入相机的内容，可在相应位置单独删除。

如果你希望查询、更正或删除主动提供给我们的反馈资料，可通过下方邮箱提出请求。我们会在处理反馈所需的期间保留相关资料，并在适用法律要求保留的范围内处理删除请求。

联系我们

关于本政策、权限或数据处理的问题，请联系 izhaoo@163.com。政策更新会在此页面公布。

第一次连接相机，需要注意什么？

在相机上开启蓝牙与无线 LAN，按应用提示连接；也可先在系统设置中接入相机 Wi-Fi。相机网络不提供互联网，请保持连接后返回 GRemote。附近设备、蓝牙与相册权限按使用功能授予。

哪些设备和功能已经开放？

当前提供 Android 8.0+ 的 arm64 安装包，主要适配 RICOH GR III；iOS 尚未开放下载。M10V 装卷与扩展为可选功能，需要兼容固件及应用识别的机身能力，不代表所有 GR 型号均可使用。手机色彩为官网 RGB 预览近似，800T、Charmera、Pixel World 暂不可用于手机修图。

升级前，需要保留哪些数据？

v1.2.3 沿用 v1.0.1 的正式签名。v1.0.0 与开发 debug 版签名不同，不能直接覆盖；请先导出重要作品、配方与记录，再处理旧安装。正式 APK 的设备兼容性与完整创作流程仍需真机验收，详见发布说明。
