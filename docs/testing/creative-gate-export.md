# 创作功能门禁：出图管线真机清单

状态：已开发／待核心相机功能门禁通过后验收。测试对象为 Android 13/14 真机与 RICOH GR III 原生 JPEG；每项记录机型、系统版本、APK SHA-256、开始/结束时间和结果。

## 准备

- 安装 `dist/gremote-0.2.0+2-arm64-debug-*.apk`，首次启动授予照片权限。
- 相册准备：GR III 横拍 JPEG、Orientation 6/8 竖拍 JPEG、带 GPS 与不带 GPS 各一张；另备其他手机 JPEG。
- LUT 准备：合法 17/33/65 点 `.cube` 各一份，以及尺寸 16、数据缺行、越界值、NaN、超过 16 MiB 的坏文件。
- 测试期间保留至少 2 GiB 可用空间；内存与耗时用 Android Studio Profiler 或 `adb shell dumpsys meminfo com.izhaoo.gremote` 记录。

## 图库与权限

- [ ] 拒绝照片权限时显示授权卡；授权后进入扫描。
- [ ] Android 14 选择“部分照片”时只显示已选内容，并显示“继续添加”。
- [ ] 默认只显示 EXIF Model 为 `RICOH GR III` 的 JPEG；切“全部”后包含手机 JPEG。
- [ ] 再次进入图库只读取新增或 `date_modified` 变化的 EXIF；系统删除的照片从列表消失。
- [ ] 相机分栏只显示前置门禁提示，不误触发相机下载。

## 单张编辑

- [ ] Orientation 1/6/8 的照片预览均为正向；长按预览显示未套 LUT 的原图。
- [ ] 5 个内置 LUT 均可切换，强度 0/50/100% 有连续、合理的变化。
- [ ] 经典白边、街拍暗金、胶片印样 × 原比例/3:4/4:5/1:1 共 12 组均完整保留照片，不裁切。
- [ ] 机型、焦距、光圈、快门、ISO、日期、标题、地点可分别隐藏；缺失 EXIF 不显示占位乱码。
- [ ] 标题与地点含中文、英文和长文本时不越界；返回图库再打开后编辑仍在。
- [ ] “存为方案”后出现在暗房，可重命名、删除并用于批量出图。

## LUT 导入

- [ ] 17/33/65 点 `.cube` 导入成功、重启后仍在、同内容换名导入不会重复。
- [ ] 尺寸 16、缺行、越界、NaN、超 16 MiB 分别显示明确原因。
- [ ] 删除导入 LUT 后条目消失；引用该 LUT 的旧编辑给出可恢复的错误，不崩溃。

## 导出与隐私

- [ ] 原始尺寸、长边 2560、长边 1440 × 质量 85/90/95/100 输出尺寸与设置一致，原图未被覆盖。
- [ ] 导出文件位于 `Pictures/gremote/`，文件名为 `gremote_<原名>_<时间>.jpg`，系统相册可立即看到。
- [ ] 默认导出无全部 GPS 标签；序列号、所有者、ImageUniqueID、MakerNote、UserComment 始终不存在。
- [ ] 授予“媒体位置”后“保留 GPS”可开启，导出副本坐标与原图一致；未授权时开关禁用并说明原因。
- [ ] 输出 Orientation=1、宽高为输出像素、Software=`gremote`；机型、镜头、时间、曝光参数、焦距保留。
- [ ] 导出完成后的“分享”能打开系统 Sharesheet，接收方可读取 JPEG。

## 批量、性能与故障

- [ ] 多选 20 张，套同一方案串行导出；每张标题/地点沿用自身编辑。
- [ ] 人为损坏第 2 张或制造读取失败，第 3 张仍继续；结束汇总成功数和失败明细，重试只处理失败项。
- [ ] 第 2 张处理中点击取消，当前项取消且剩余项标记取消；无 `.part`、缓存临时文件或半成品相册条目残留。
- [ ] 一张 24 MP 原始尺寸 + 65 点 LUT 导出成功；记录耗时与峰值 PSS，目标峰值不高于 180 MiB。
- [ ] 存储空间不足、权限撤销、源图被删除、坏 JPEG 均显示阶段、文件名、错误码、原因与下一步。
- [ ] 批量导出时切后台再返回，界面状态一致；验证系统暂停或杀进程时没有半成品。

## 门禁结论

只有核心相机功能门禁已通过、上述项目全部通过、无崩溃/ANR/原图修改/GPS 默认泄露，才可把创作功能门禁标记为通过。任一隐私或原图安全问题均为阻断项。
