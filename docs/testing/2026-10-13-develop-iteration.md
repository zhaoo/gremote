## 对焦与中文界面

旧对焦按钮复用快门按下/释放，BLE 模拟路径会生成照片，手动 Wi-Fi 路径会直接调用拍照接口。改为独立镜头对焦请求，不允许回退至快门。请求进行中禁止重复对焦或手动快门，快门按住时禁止对焦；错误可重试，断连后的旧请求不报告成功。中文反馈只表示已发送请求，不代表已成功合焦。

复核补修：按住快门断连时同步清除页面及按钮的按压状态，避免禁用手势造成构建期间的取消回调异常；作废旧连接的延迟释放与拍摄标记，重连后对焦和下一次拍照恢复可用。固件 `hiContrastBW`、`hdrTone` 分别显示为高对比黑白和高动态色调。

固件已包含 `POST /v1/lens/focus`、`focus_pos` 整数二元组及 `pos` 参数。现有 API 的 0–100 坐标单位仍未实机验证，当前中心请求为 `50,50`。应在 GR III 2.10 上核对中心位置、自动/手动对焦模式、拒绝状态与合焦反馈。

拍摄按钮、参数名与选项、曝光模式、影像效果、配方选择、暂停原因使用中文展示；相机请求与存储继续使用原始协议值。更多参数页补齐原先未展示的对焦、驱动、效果及照片格式。

## 相机原图保存

增加显式“选择”入口、点选多张、全选/清除、全部/JPEG/RAW 格式选择。批量保存显示当前文件与文件数进度；失败不阻断后续文件，保留失败项选择供重试。断连与离开页面会作废旧缩略图队列、选择及回调。

从相机分栏返回本机分栏时重新扫描本地媒体，新保存的照片无需重启应用即可出现在本机图库。

缩略图最多并发两个；保存原图前等待已有缩略图完成，整个批次暂停排队缩略图。原图保持 Wi-Fi HTTP `size=full`，直接流式写入系统相册。流式缓冲调整至 64 KiB，增加断连后的调用准入保护和脱敏耗时记录。详见 [固件证据、性能分析与测量方法](../camera-transfer-performance.md)。

JVM 夹具对 1 MiB + 13 字节逐字节核对，写调用从默认 8 KiB 的 129 次减为 17 次。这是本地 IO 调用数证据，不能换算为相机实际提速比例。没有静态证据证明 Range 续传或并行原图可靠，未启用这些优化。

## 出图样式

- 增加“无边框”，原比例时不添加边框、文字或额外像素。
- 经典白边、街拍暗金按照片短边缩小边距；个人标题在上、机型与曝光参数在下，隐藏信息后去除空信息栏。
- 暗金改为短装饰线；胶片印样缩小片孔、降低装饰对比度，移除强制品牌与固定编号。
- 边框选择改为带缩略样式和说明的卡片。预览和导出共用排版与绘制器，字间距随缩放一致变化。

`tool/render_frame_previews.dart` 生成横图与竖图预览；人工检查照片完整、中文显示、文字不相撞。宿主机预览加载本地中文字体，仅用于排版检查，不代替 Android 字体与最终出图验收。
