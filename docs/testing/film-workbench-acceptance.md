# GRemote × M10V 测试候选验收

本次为离线验证候选。App 的试卷台、数字胶卷、联系印样与配方管理可测试；完整无线装卷尚未交付为可用真机功能。实际 GR III 驻留 owner、持续 cache 一致性、wakeup/lifetime、Wi-Fi 接口适配和本地菜单共用提交域仍缺少实现与证据。目标 getter 保持 unavailable，普通固件默认不启用伴侣服务。**当前相机候选仅供离线审计，不得作为无线可用版本安装。**

## 当前候选可验收

1. 核对 `manifest.json` 的 buildId、APK SHA256、renderer/catalog/registry 指纹；用 `SHA256SUMS` 校验包内文件。不要以同版本号替代内容身份。
2. 在测试手机自愿安装 APK 后，打开「试卷台」：目录/搜索/近似预览与参数范围正确；拖动分界不触发相机请求；在小屏、文字放大和减少动画设置下可操作。
3. 用本地 JPEG 试色；对已处理照片默认不再套色，明确开启后才叠加。离开页面与后台停止取帧/轮询，旧预览结果不覆盖新选择；延迟解码仍可能在不可见时完成一次渲染（已列为待修资源问题）。
4. 开一卷并手动归档同一张照片两次；计数只增一次，替换照片引用不改变冻结配方。关闭卷后仍可查看，下一卷独立。
5. 选择照片或全卷导出；超过 24 张分页；缺片/坏缩略图有占位与缺图数；取消不新增半成品；失败后只重试失败页；原片不变，JPEG 不二次套色。
6. 导入数据配方卡或 `.m10vfilm`；错误 schema、机型、哈希、额外字段、旧 renderer 拒绝并保留现状。配方分享不包含 GPS/密钥。
7. 「相机胶卷」未连接/未配对时呈现真实空态；只读/不支持组件不会显示已同步或可写假槽位。当前 iOS 明确显示网络能力未支持。
8. 反馈只发送 buildId、脱敏 manifest、操作步骤和必要的脱敏截图。`private/pairing.json` 与相机服务二进制包含私有密钥，整个测试包不要公开分享。

## 后续真实无线验收（当前阻塞）

以下项目必须等 owner/cache/wakeup/lifetime/Wi-Fi 适配完成，生成**新的 installable 候选 hash**，并由用户针对该候选明确授权安装后执行；本次不执行安装、刷写、脚本启动或部署。

| 顺序 | 验收重点 |
|---|---|
| 连接/只读 | GR III 2.10 + Android；确认实际绑定 Network、模型/固件/构建身份，响应签名、重连/换网后的旧会话丢弃。 |
| 装卷 | 任意槽替换只改目标槽和一次 journal；完整读回才 synced；配置与当前 tone 切换分离；切换失败准确提示“已装入，切换失败”。 |
| 机身改动 | 本地菜单和远程共用真实提交域；B/L/R 单端变化、同值、冲突逐字段确认；保留两份只存本地配方，不占其他槽。 |
| 断线/重启 | 提交前失败不改旧配置；ACK 丢失/写后读回失败保留 unknown；同 boot 同 ID 不重复写；新 boot 只读比较并重新确认，不盲重放。 |
| 文件/空间 | 无卡、短读、满卡、坏 CRC/哈希、过期 renderer、断传；引用未知或当前/排队捕获占用 bank 时 busy；完整读回前不激活。 |
| 拍摄兼容 | 首张、连拍、RAW+JPEG、迟到 RAW、回放/关机/换卡；原有 HDF、日期/胶卷名、裁切、水平仪、NR 等逐项回归；RAW 像素不变。 |
| 性能 | 真机分别记录快门延迟、服务响应、预览帧耗时与内存、原图传输速度；主机测试和构建不作替代。 |
| 撤除 | 关机后仅撤本功能拥有的文件/include，保留用户其他 SD 脚本、STARTUP 和照片；不清空 journal；官方回退遵守既有验证流程。 |

每次反馈绑定：设备/固件/系统/候选 SHA、复现步骤、预期/实际、是否首次/连续/RAW+JPEG、脱敏日志及恢复结果。故障修复后生成新 hash 重新验收；未获该 hash 真机通过，不推送主线、GitHub 或宝塔。
