# Wi-Fi 网络选择

开发分支：`develop`。首页原“手动连接 Wi-Fi”入口改为“选择 Wi-Fi 连接”。

使用方式：先在相机中开启无线 LAN，点击入口和“扫描附近 Wi-Fi”，从列表选择相机网络，再输入相机密码并连接。不需要手动填写 SSID；扫描不可用时点击“手动输入网络名称”。扫描列表和手动输入均保留 SSID 原值，不删除真实名称的首尾空格。

RICOH 前缀网络优先展示，其余按信号排序。同名网络合并为最强信号，最多显示 64 个。扫描期间禁止重复刷新或提交连接。密码不保存、不进入扫描请求或日志，连接仍经原有相机身份探测。

Android 的 `startScan`/`getScanResults` 即使在 Android 13+ 也需要精确位置权限及系统定位开关。因此扫描按钮前说明用途，仅在点击扫描后请求权限；蓝牙连接入口不增加此权限要求。定位、Wi-Fi 开关或权限不足时显示修复提示，并保留手动输入。参考：[Android 官方 Wi-Fi 扫描说明](https://developer.android.com/develop/connectivity/wifi/wifi-scan)。

每次扫描等待最多 7 秒；系统限制刷新或未收到新扫描时返回最近的系统列表，界面明确提示结果未更新。暂停/退出时清理广播接收器。列表不包含 BSSID、密码或坐标。

回归覆盖：扫描列表选择后只需密码、拒绝扫描权限后手动输入、SSID 首尾空格保留、并发扫描合并、权限拒绝不启动原生扫描，以及原生网络去重/排序/数量限制。真机 Wi-Fi 扫描和 GR III 网络连接仍待设备验证。
