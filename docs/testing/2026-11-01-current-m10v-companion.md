# 最新 M10V 胶卷设置联调

状态：v2 已安装到 GR III；本次真机认证读取、参数保存与回读、App 装卷、正式切槽及相机关机重启后的持久状态检查通过。性能和长期兼容性仍未验收。

## 本次范围

- 独立相机胶卷目录：51 款、十槽、当前启用槽与参数读取；保留原有手机胶卷目录、调色引擎和已存配方。
- 装卷采用“读取当前配置 → 确认实际槽位 → 单次保存 → 读回确认 → 单独切换启用槽”。重复胶卷复用原槽，新胶卷遵守机内连续槽位规则。
- 机身由原厂 UI 定时器处理请求，使用原有双份存档和正式色调 setter。Linux 只提交独立邮箱请求，不调用 RTOS 函数，不写照片卷。
- 颗粒尺寸、旧漏光字节保留读取，禁止通过该写入路径修改；自定义 LUT 无线上传保持关闭。

## 独立审查与修复

独立审查发现三项重要问题，均先复现失败再修复：

1. 远程读取接受了旧版迁移或默认回退状态。现改为只扫描当前版本两份存档，不迁移、不生成默认状态、不发布预览缓存；提交前也要求明确成功。
2. 本地保存或修改期间仍能读出“有效快照”。现检查共享存储门禁、本地修改忙态及 I/O 前后的修改代际；读取期间完成一次本地保存也使本次快照失效。
3. 原厂 I/O 重入后，旧请求可能发布到继任页面。现于写后、读后验证原 token，并只向原缓存对象发布；已经发出的磁盘写入仍按结果未知处理，不声称回滚。

## 实施取舍

- 以最新 main 为基线隔离实现，原有脏工作区保持不动；五槽旧合同没有覆盖十槽存档。
- 沿用已确认的视觉方向，保留旧手机渲染器；不支持的旧配方显式拒绝转换，避免静默改变效果。
- 邮箱内存保留至关机，换页面时撤销并取消回调，避免 Linux 的迟到写入落入复用堆；反复重建页面的内存累计仍待设备验证。
- 服务仅在构建/owner/邮箱身份匹配、双向 HELLO 成功且无线接口核实后监听。超时或半发布后封闭本次会话，不自动重放写入；重新测试需要关机重启。
- Mac 只读 SD；先把包传到手机，再由用户关机写卡。测试包未获本机验收前不合并 main、不推送、不部署生产。

## 设备验收顺序

1. 安装匹配的新固件与 SD 服务，手机安装 APK 并导入本包私有配对文件。
2. 正常开机并连接相机 Wi-Fi，读取十槽、参数和当前启用槽，与机身菜单逐项核对。
3. 只改一项已支持参数，确认保存一次并读回；再独立切换启用槽。
4. 使用 App 完成装卷，确认其他槽和旧保留参数不变；断连或未知结果时不重复提交。
5. 检查关机重启后的持久状态，以及原有拍摄、回放和连续拍摄体验。
