## 已确认的源码行为与修复

普通相机 HTTP 连接与 M10V 服务是独立链路。M10V 使用相机 Wi-Fi 的 18743 端口；服务需与固件桥接身份配套。最新 M10V 的 GRemote 构建需要显式开启连接功能，下载 ZIP 中的固件、SERVICE.BIN、SERVICE.SH 和 STARTUP.TTL 需配套使用。只更新 BIN、未放服务、未启用脚本或沿用不匹配的旧服务，都可能导致界面已连接相机但 M10V 不可用；具体设备原因仍需读取确认。

App 自动发现此前在 401/404 及一般异常分支直接返回，部分失败后不再探测。修复为无旧配对时每 20 秒重新只读发现；一般异常沿用 1/2/4 秒退避，再进入周期发现。有旧配对的 401/404 保留既有回退，不周期打断旧会话。平台不支持、目标非法和连接变化仍停止当前探测。两页提供重试连接及配套 SD 服务检查提示。没有重放写请求、改变请求字段或增加拍摄/对焦操作。
