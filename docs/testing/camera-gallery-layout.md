# 相机图库选择与下载布局修复

用户截图显示进入选择模式或下载时工具栏重叠、网格消失。

根因：应用 FilledButton 主题设置 `Size.fromHeight(46)`，包含无限最小宽度。图库底部按钮直接处于 Row 的非弹性子节点中，触发 `BoxConstraints forces an infinite width`，后续渲染布局失败。此前测试使用默认 MaterialApp 主题，未覆盖真实应用约束。

已将保存按钮放入 Expanded 提供有限宽度。回归测试改用 GRemoteTheme.dark，覆盖 320×640 窄屏、长按进入选择、多个照片选择与 JPEG 筛选、失败项保留及下载期间网格继续存在。

界面：明确“多选”入口，计数在标题下方；格式选择、全选与清除在独立工具卡内；下载进度固定在底部区域，文件名截断、数量和进度条独立排布；完成结果内联显示。
