## 行为

- 底栏实际路由顺序：首页、相册、拍摄、相机；拍摄页隐藏底栏，保留退出和方向恢复。

- 照片/文档并行读取；LUT 列表和位置权限独立加载，不阻塞首帧。正式 GPU 帧之前复用相册缩略图并禁用导出；不把缩略图作为导出输入。
- 曲线图区域立即取得手势，图外仍可滚动；覆盖慢速分步纵向拖动、点选、删除和取消。
- 官网数字数据转换为不可变、内容寻址的 .cube，进入既有 GPU/CPU 修图与导出同一路径；旧编辑保留旧 payload。暂存全部文件后原子更新活动清单，失败不替换旧库。
- 「用于修图」进入相册选择照片；LUT ID 严格校验，应用一次且可撤销。首次转交后清除相册 query，防止再次打开照片时覆盖后来保存的 LUT。
- 两套受信任机内目录：已安装 03db1c70（653acf/80a4）和当前 main（5d3ec9/7595）。从已认证 capabilities 选择，未知版本只读；旧配方不重绑新 hash。官网版本不一致时可明确选择机身版本，不能把新版数据当旧卷写入。
- SD 导出走手机系统文件选择器，用户选择目标；仅导出 FILMS.M10，不自动写相机或无线替换整库。新 SD 库仍须匹配固件，替换前保留旧文件，包含自定义 LUT 时不能盲目覆盖。

## 范围与裁定

官网当前 56 卷均可同步元数据/SD 文件，其中 53 款、56 个 EI 色彩变体可以用于手机修图。800T（33）、Charmera（289）和 Pixel World（290）没有本次支持的可移植手机色彩格式，明确显示暂不可用；未生成替代 LUT 或声称空间效果/机内成片完全一致。手机色彩为官网 RGB 预览近似。

部分 SD kind3 记录只包含引擎数据摘要，不能解析为 LUT。本次下载实际数值 JSON，不执行远程 JS；对原生色表家族验证其与 SD 记录的摘要绑定，检测跨部署混合版本。旧固件不认识的新卷仍需要匹配固件，未绕过此边界。

相机端整库无线写入并未实现或启用。手机读卡器导出路径可用，不将这两种能力混淆。
