# 首次连接优化

本轮开发位于 `develop`，连接入口使用蓝牙与 Wi-Fi。

## 首次连接

系统权限请求期间显示独立的权限检查阶段，连接入口不再接受重复请求。Android 权限弹窗即使尚未关闭，取消后再次连接也会等待同一次请求完成；被取消的旧尝试不会继续扫描。手动 Wi-Fi 独立检查自身权限，不继承蓝牙被拒绝的结果。

原生 Wi-Fi 取消会立即结束等待，注销后的旧可用/不可用/断线回调不能修改新连接。系统 Wi-Fi 连接提示与应用权限提示分别展示；允许后显示正在等待网络连接，不再一直提示重复授权。

这些缺口由自动化回归复现并修正。自动化结果不能确认用户首次连接卡顿已在小米手机消失；真机复测时应记录卡住的具体阶段和脱敏连接诊断。

## 验证范围

保留权限请求去重/取消、蓝牙拒绝与手动 Wi-Fi 独立授权、旧 Wi-Fi 回调隔离与取消的自动化回归。模拟测试与构建结果不能替代真机首次连接兼容性结论。

2026-10-13 历史完整构建曾通过静态分析、310 项 Flutter 测试、65 项 Android 单元测试和原生图像 CTest，arm64 debug APK 构建成功。该结果来自本次移除前的版本，不能代表当前版本的测试数量或验证结果。当前版本的验证见本轮迭代记录。
