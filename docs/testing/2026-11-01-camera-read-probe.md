## 实现和边界

TTL 独立分配 16-word 临时数组，通过同步 lcmd 启动 Linux ARM 程序。程序仅以 O_RDONLY/PROT_READ 读取 ROM、数组描述符和探针数据，复查描述符及数据后关闭 /dev/mem。仅在核实的相机 Wi-Fi 接口 192.168.0.1:18743 短时提供固定 GET 路径。每次调用成功响应一次后退出；相同 runId 的 16 个轮次共发布 3 遍（最多 48 次调用），允许后续遍补回启动尚未就绪时遗漏的轮次。手机按轮次去重，证据可跨遍历；有限重试不保证 Linux 就绪。无采集时脚本最多运行约 9 分钟，采集器最多等待 600 秒。其他 App 路径或写方法不会占用有效响应。

Linux 不写 RAM 或 SD，不安装 Hook，不留后台服务。TTL 仅通过 RTOS 文件 API 写探针目录内的报告。报告最多证明脚本发布请求；手机采集器须验证同一运行全部 16 轮，才记录 READ_TRANSFER_OBSERVED。该结果也不能证明双向内存一致性、真实设置读取、设置提交或拍摄性能。
