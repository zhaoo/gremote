## 实现

- 四栏：首页、相册、相机、拍摄；首页连接、定位、导入状态保留，移除营销文案和试卷台入口。
- 相册：日期三列，明确 JPEG 导入；相册集合仅包含已下载/主动导入照片，不受 GR 型号过滤；流式源哈希去重，复制原始 JPEG 保留 EXIF，系统授权仍按现有流程处理。
- 点按直达原非破坏编辑器；长按 Save/Share 用真实 ExportService 读取已保存编辑并生成副本，分享的是生成副本；批量出图从显式选择入口保留。
- 相机来源页面在来源切换后保留，下载 URI 注册至应用相册。RAW 继续保留原下载语义，本次不新增 RAW 编辑。
- 相机：胶卷表格、查找、类型、详情和标明来源的参考预览；十槽页复用原配对/读取/差异确认/写入/回读/启用流程。
- 官网同步实际目录和 SD 文件；仅接受限制大小的 HTTPS 响应和网站存储 ZIP；校验机型、数量、记录 ID、CRC、每条 renderer，最终以单文件原子替换缓存。失败保持旧缓存，绝不覆盖内置相机协议或手机预览渲染器。
- 自定义 LUT 真实导入手机持久库并显示于“我的 LUT”，可用于照片编辑。当前 uploadFilm=false，不宣称可以无线传任意 cube 到机内。
- 扩展显示当前可操作的胶卷颗粒/光晕入口与缺少 RPC 的功能分组。快切、Half、全局效果、水印、焦距、画幅、开关机图片的新增固件遥控接口属于后续交付，本次不伪造开关。

- 下载在相册已显示时完成，立即触发相册扫描；正在扫描时到来的请求排队再扫，不丢刷新。新增可见相册后台完成测试和扫描排队测试。

## 实施取舍

- 按已批准计划直接推进，保留独立分支待真机验收。所有原工作区修改保留。
- 保存与分享统一读取持久编辑，导出 JPEG 副本后使用系统 API。代价是分享也生成系统相册副本；原图保持不变。
- 相册只迁入已知下载/导入目录；主动 JPEG 导入完整复制保留 EXIF，并对源字节做流式哈希去重。代价是旧的任意系统 GR 图片需要主动导入；RAW 保留下载能力，编辑沿用 JPEG 引擎。
- 十槽保留独立全屏页复用已有确认事务；代价是从库到槽位多一步。新增相机 UI 集中在两个文件，避免重复实现事务。
- 官网 SD 文件与手机渲染目录分开；同步仍要求每条记录匹配固定 camera renderer，远端错误或新 renderer 保留旧缓存；写入继续使用固定合同。代价是新固件目录需要对应 App 适配，不能用同步绕过兼容性。
- 当前自定义 LUT 仅手机编辑；新增机内 RPC 和专业图片算法为后续功能，没有用空控件冒充支持。
- 没有物理设备时，保留真实硬件、系统权限/分享接收端/旋转验收边界；不能从宿主测试推断真机已通过。
