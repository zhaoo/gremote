# GR III 2.10 拍摄配方阶段验证

M10V 诊断包使用 build ID `0ee08014`。Android APK 使用版本 1.2.13 (38)。固件和 SD 服务来自上一轮同一套已完成离线校验的候选。

1. 手机连接相机 Wi-Fi，打开 GRemote「相机」。点右上角的连接菜单，进入「拍摄配方」。
2. 先在机内启用一款已装入的胶卷，设置白平衡和一个效果。在 App 点「保存当前配方」，输入名称。App 保存当前可写的拍摄参数、已读回的胶卷设置和可用的配方效果。应用时会检查这些值能否在目标机身上恢复。
3. 在相机切换到另一款已装入的胶卷，修改白平衡。点已存配方，核对变化后应用。曝光默认保持当前值，可以单独勾选同时应用。
4. 机身回读完成后，核对胶卷与实际参数，再点「撤销上次应用」。用同一台相机和当前页面验证恢复。遇到断线或未知结果，先核对机身和回执。
5. 拍 RAW+JPEG，切换胶卷后传回先前的文件。在相机照片文件面板核对原拍胶卷并查看同款胶卷配方。长按已下载的 JPEG，可再次按原图身份查找已存配方。当前只有胶卷身份来自照片，完整历史快照尚未关联。
6. 机内用同一 DNG 以 As Shot 和另一受支持胶卷显影，正常关机后从 SD 根目录取回 `M10VCP0.BIN`、`M10VCP1.BIN`。在 GRemote 诊断页导出 App 日志。日志中的 `shootingRecipe` 记录操作时长及回读失败类别。

后续源码为 Android 手机单拍增加了快门前后配方读回。两次结果及设定修订号必须一致，之后按相机、目录、同名 JPG/DNG、拍摄时间及原图胶卷编号匹配。下载后提供「应用手机记录的拍摄配方」，保留写入结果核对和撤销。应用日志的 `photoShootingRecipe` 标记原图关联结果，`filmIdentityOnly` 表示仅找到了胶卷编号。上述步骤 1–6 所列旧包不含这项更改。

待验证机内曝光快照的写出，以及机身独立拍摄、连拍、程序拍摄和 iOS 照片回读。U1/U2/U3 离线拨盘绑定和 ADJ 取景试配方尚未接通。
