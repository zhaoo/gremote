# GRemote 发布官网与交付设计

日期：2026-10-19。视觉方向：用户已选择 A「纸感摄影志」。iOS 分发：用户已选择 TestFlight。

## 目标与范围

在 `develop` 完成中文官网、Android 正式发布准备、iOS TestFlight 适配及 `gremote.izhaoo.com` 宝塔交付。分为官网与部署、Android 签名、iOS 适配三个独立交付单元；官网可先上线，不依赖 iOS 完成。既有 v1.0.0 资产和用户改动必须保留。

## 官网

使用静态 HTML、CSS、少量原生 JavaScript，不引入后端或账号系统。源文件放在 `website/`，不改动 Flutter 自带 Web 目录。暖白底色、炭黑正文、橙色强调、衬线大标题与无衬线正文；保留 A 稿的摄影留白和非对称构图。采用已有相机图片与街拍素材；产品界面使用真实截图，未取得截图的区域用清晰图文说明，不以生成界面充当实际功能。

页面按以下顺序组织：

1. 导航：介绍、使用方法、发布记录、GitHub；手机端折叠菜单。
2. 首屏：“把街头，装进口袋。”介绍 GR III 伴侣定位，提供 Android 下载、使用方法入口；iOS 在 TestFlight 真正可用前显示“TestFlight 准备中”。
3. 功能介绍：连接相机、遥控拍摄、照片传输、暗房创作。按实际代码和验收记录描述，不承诺未验证的机型、速度或稳定性。
4. 使用方法：开启相机无线功能并连接、取景拍摄与传输、创作导出；增加权限与连接问题的可展开说明。对焦与快门分别说明。
5. 发布记录：以仓库发布说明为依据，展示版本、真实日期、更新项、验证范围与下载入口。通过本地 `releases.json` 维护，不依赖浏览器实时访问 GitHub API。
6. 页脚：GitHub、独立项目声明和本地处理说明；隐私描述必须符合实际权限和数据行为。

交互采用锚点导航、轻微进入动效、清晰 hover/focus 状态、原生可访问的折叠说明。尊重 `prefers-reduced-motion`；所有功能键盘可操作。适配 360px 手机、平板和桌面，避免横向溢出。下载为真实链接，不提供假成功提示。TestFlight 未开放时不出现可点击的邀请按钮。

## Android 发布

当前 `1.0.0+3` 重新构建的 APK 与 GitHub v1.0.0 SHA-256 一致：`545a662870542ea3594ffea8357549c09d800a40bd96def3ad5855cfba5b5025`。该版本使用 debug 签名，不能将其描述为正式密钥签名。

新增正式签名配置时从本机私有配置或 CI secrets 读取，密钥和密码不进入 Git、日志或文档。发布构建缺少配置时明确失败，不静默回退 debug 签名。正式密钥与旧 APK 不一致时，必须说明旧安装不能直接覆盖升级，且卸载可能丢失本地数据。新资产使用新版本和递增 versionCode，不覆盖旧 Release。只有签名验证、构建检查和发布说明齐全后上传 GitHub，并回查资产及 SHA-256。

## iOS TestFlight

当前没有 `ios/` 工程，本机无完整 Xcode 和有效签名身份。iOS 是完整的平台适配工作，不能靠生成工程或无签名编译交付。

先盘点 Pigeon 接口、BLE、相机 Wi-Fi/本地网络通信、相册读写、定位和原生图像库；补齐 Swift 实现、权限文案、生命周期与 C++ 链接。iOS 的网络选择由系统限制决定，不承诺与 Android 相同的自动接入体验。保留对焦/快门分离和原图不覆盖约定。

需要完整 Xcode、Apple Developer 团队权限及 App Store Connect 应用记录；通过用户登录或专用 CI secrets 提供，不在对话中索取密钥明文。完成 archive、签名校验、上传处理后，以真实邀请链接为可分发标志。真机必须验证连接、Live View、快门、JPG/RAW 传输、相册权限及导出；尚未完成的验收逐项记录，不能用模拟器或构建代替。

## 宝塔部署

借鉴 M10V 的受限发布、版本核验和回滚方式，GRemote 使用独立静态目录和独立虚拟主机，不复用 M10V 的服务或受限密钥。部署文件放在 `deploy/`。服务器地址、登录能力和 Nginx 配置在修改前现场核验；M10V 文档中存在新旧主机差异，不能直接复制命令。

建议站点路径 `/www/wwwroot/gremote`，静态版本先写入独立 releases 目录，校验后切换 current 链接，保留上一个版本用于回滚。拒绝目录遍历及不完整发布包；发布入口限制目标路径和操作范围。若使用 GitHub Actions，采用手动发布以在 develop 工作约定下避免每次推送自动上线，并固定 SSH 主机指纹。

域名当前没有 DNS 记录；核对目标 IP 后配置 DNS、独立 Nginx 站点、HTTPS 与续期。缺少 DNS/宝塔访问条件时完成本地可审阅文件，明确记录阻塞项，不宣称上线。

## 验收

- 官网：真实浏览器检查桌面与手机布局、导航、菜单、折叠说明、下载链接、键盘和减少动画模式；核对发布记录与实际资产。
- 部署：检查 Nginx 配置，通过公网验证 HTTPS、证书、页面资源和版本标识，并实际确认回滚路径。
- Android：分析、相关测试、release 构建、签名身份、版本号与 APK 校验；真机验收另列。
- iOS：原生实现及签名检查、TestFlight 构建处理状态和真机记录；待全部满足后再声明可测试。
