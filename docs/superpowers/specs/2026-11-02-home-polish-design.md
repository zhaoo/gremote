- 品牌采用 B：圆形光圈搭配 GRemote 衬线字标。经过两次缩小，视觉稿宽约 108、整体高约 26 逻辑像素；不得恢复大 Logo。
- 默认主图采用原 App 文案。“走上 / 街头”错位分行，前者 21、后者 43；左下保留“让平凡的日子， / 留下不平凡的眼光。”，11 号辅助文字。主图人物与明暗关系保持清晰。
- 相机区域沿用纸感画册方案的机型层级与整行拍摄按钮，配色服从深灰主题。RICOH 小标题、GR III 衬线大标题，右侧恢复原 GR 相机图片；按真实连接身份显示机型。
- 今日导入、位置记录继续为简洁列表。底栏顺序：首页、相册、相机、拍摄，无选中下划线。

## 作品封面

用户提出导入相册后用自己的照片轮播，随后确认首页定稿，包含以下已讨论规则：

1. 无可用照片时显示默认街景与 slogan。
2. 有本地相册照片后，优先显示用户指定封面；未指定时使用最近导入的最多 5 张。
3. 左右滑动。自动播放可关闭，开启时每 8 秒轻柔淡入；触摸暂停。单张固定封面不自动播放。
4. 用户作品不叠加 slogan，仅保留低干扰的分页提示。
5. 横竖构图允许用户调整取景位置，保存的是封面展示参数，不修改原图。
6. 长按进入“作品封面”管理，可选图、调整顺序、固定单张、切换自动播放、恢复默认封面。

默认实现选择：自动播放初始开启；触摸、页面隐藏、App 后台、管理面板打开时暂停；回到可见且无手势后重新等待完整 8 秒。系统减少动态效果时停用自动切换，保留手动选择。淡入使用短过渡，不加缩放或持续漂移动效。

“最近导入”以 album_collection.added_at 排序，不能误用拍摄日期。来源只限 App 相册已下载/主动导入的本地照片，不读取相机远程目录，不自动索取新权限或扩大到整个系统相册。

封面配置本地持久化；图片删除、权限撤销、缩略图不可读时不展示失效缓存，不改写原图，不清除用户原先选图意图；可读照片均失效时回到默认街景。权限恢复或照片重新可读后重新核对配置。

## 保留现有功能

连接、蓝牙/Wi-Fi 选择、权限与故障恢复、取消连接、手动 Wi-Fi、诊断、协议探测、今日导入和定位控制都保留。真实设备与固件警告不能被“文案精简”隐藏。拍摄入口仍复用既有路由，自动轮播不触发任何相机操作。所有 UI 展示使用中文；协议字段和值不变。

## 本轮边界

仅首页、必要封面管理和共享底栏视觉。相册、编辑器、相机设置和拍摄页仍逐页先出稿再实施。M10V 扩展调试继续暂停，不修固件、不操作设备、不触发生产发布。

GRemote 实施必须在 develop，保留已有改动。视觉稿通过、组件测试通过、APK 构建和 USB 真机观感分别记录，不能互相替代。
