# M10V 遥控扩展设置

沿用用户已批准的“相机→扩展”分组和简洁视觉。用户本轮要求继续完成，不重复设计审批。GRemote 在 develop 修改；M10V 以最新 main a24ccc2 创建独立候选，移入当前已验证 companion owner 三个提交，保护原脏工作区。

选择独立扩展协议，而非扩充胶卷响应：老 App 对胶卷能力未知键会禁写，新接口不能破坏旧版本。沿用同一 HMAC、会话、网络绑定、严格路径门禁和 AppMain owner。独立 m10v.extensions/v1/schemaHash；电影目录和 renderer 固定合同不变。

21 个数值字段：快切开关/A/B；HDF；边框；颗粒模式/尺寸；漏光强度/位置/范围；模糊强度/范围；时间水印/格式/角落/颜色；胶卷名水印；两档焦距/当前档；画幅。Half 是画幅 raw6，其他 raw 顺序是 3:2=0、4:3=1、16:9=2、1:1=3、XPan=4、6x7=5；不能将显示顺序当协议值。快切22候选包含原厂12种及十槽，配对不同且所选胶卷槽必须有效；快切开关重启关闭，配对持久。其余字段按实际 journal/相机模型语义标注，禁止承诺跨 journal 原子保存。

每次提交一个字段。先读取当前真实值和支持能力，修改本地草稿，确认保存；写入前检查前台、连接、当前配对、拍摄/程序/原图传输及其他 pending 操作。持久记录 requestId/原始 payload 后仅提交一次。owner 内验证 boot/schema/revision、忙状态与共享锁，调用原生已验证 setter/journal，读取真实状态对照后才报告 committed。超时、断连或未知回执只查询原请求；不能自动重放。保存后额外读取快照验证；不能用乐观值替代回读。跨胶卷/扩展共用未决门禁。

旧固件的已签名404显示需要更新伴侣组件，胶卷功能保持可用。能力未开启的模块禁用并说明原因，不把默认0伪装为已读取。开关机画面是固定固件资源，无运行时 setter/SD loader，本轮显示“需制作固件并重启”，不伪造无线替换；动态加载需独立固件研究。

新候选通过原有 full GR III 构建链启用已有 HDF、border、pure ISP effects、A/B、aspect/Half 模块，保留 native ISP/RAW/队列快照与全部存档。新 firmware、SD服务和App分别标识/hash。电脑测试/构建不是实机验收；用户安装新固件后再验证读取/单字段写入/重启持久/机身更改回读/拍摄忙保护，不自动拍照、不自动刷机、不发布生产。
