# 修图交互细化、设置与浅色主题（待视觉确认）

## 用户决定

沿用GPU迁移设计。用户要求修图UI精致、优雅、简洁，明确喜欢VSCO；新增首页右上角「… → 设置」，支持深色/浅色/跟随系统。深色保持已确认风格，浅色参考VSCO。用户另要求首页Logo透明，不能有白色底块。

本轮只完成交互稿和设计核对，未将这些变化安装进App。修图GPU预览和导出工作继续按既定目标推进，界面方案不代表GPU迁移、画质或真机性能已通过。

## 界面与操作

主路径为「预设 / 调整 / 记录」，进入单工具后收起其他入口，只保留当前相关控件。照片完整显示，横竖比例不为填满屏幕而裁切。文件名降为次要信息；导出保留在右上角，去除常驻“调整中/已保存”等正常状态文案，保存失败和待处理错误仍要可见。

### 预设

- 使用当前照片生成的LUT缩略图；全部/最近/收藏为真正筛选，导入LUT仍有入口。缩略图和实际照片均使用相同processVersion与参数。
- 点选预设即预览；再次点击同一预设或强度进入强度调节。预览选择可撤销，单工具的取消恢复进入时状态；完成才确认该工具草稿。
- 工作区切换时，已预览选择必须按明确的确认或取消规则处理；不能隐藏未确认草稿。交互稿用即时预览示意，实际实现沿用工具事务，预设选择阶段提供应用/取消控制。
- 强度、收藏和导入可直接找到。按住原图对比、释放/取消恢复，不把缩略效果当作原尺寸导出。

### 基础与曲线

- 基础采用单参数数值+细刻度滑杆，参数切换在一行内；双击数值恢复默认，轻点进入数值精调。触感只用于有意义的零点/步进，尊重App和系统设置。
- 曲线采用精简通道选择、低对比度网格和真实直方图，控制点有扩大触摸区域；输入/输出坐标可点开精调，只有中间点可删除。
- 曲线指针位置直接更新，不插值动画、不等待GPU完成才移动控件。外层滚动与曲线拖动互斥，双指缩放与单指调节有清楚的手势边界。
- 保留撤销/重做、单工具取消/完成与还原。主题变化、系统亮度切换不提交或取消工具、不改变参数，也不提升照片内容的编辑历史。
- 面板进出约150–180ms的轻过渡；控制点和刻度不做弹簧/拖尾动画，减少动态效果时关闭非必要动画。

### 其余能力

调整页保留基础、曲线、白平衡、LUT、裁切、颗粒、暗角、褪色、光晕、柔光、漏光、黑白、边框和日期印记；预设和编辑记录进入主路径。保留照片信息、方案保存、原尺寸/2560/1440、质量、GPS、保存副本及分享。保存/导出错误、原图权限、结果未知等真实状态不因追求简洁而删除。

路径：首页右上角「…」菜单新增「设置」，原有「手动连接Wi-Fi」「诊断信息」保留。设置为独立路由，返回保留首页状态，不重连相机或重新请求权限。菜单tooltip改为通用“更多”。

首批内容收敛为：

3. 关于：实际版本号与开源许可。使用真实包信息/许可证数据，不硬编码稿中示例版本。

不添加尚未定义归属的“清理缓存”、升级固件或账号管理等入口。

## 深浅主题

- 深色保留当前语义色：底色#171A1D、抬升表面#23272A、文字#EFEEE8、辅助文字#9CA3A6、分隔#343A3E。新修图区域可用同色系轻微层次，不能回到旧金色描边或过度卡片化。
- 浅色以温润白#F7F6F2为底、浅表面#F2F1EC、炭黑#222725、辅助文字#6B726F、细分隔#D9DCD5。选中控件以中性深浅反转，不增加装饰性主题色。错误/警告保留适当对比度和语义。
- 主题作用于首页、相册、相机、拍摄、修图、设置、弹层、菜单、加载/错误状态及系统状态/导航栏。相机取景画面上的叠加控件按画面背景维持可读性，不机械反色。
- 图片、LUT样片、机身图不反色；导出照片的边框/文字本身属于图片内容，不能由界面主题改变。
- Logo使用同一既有轮廓的真实alpha蒙版，深色前景为暖白，浅色前景为炭黑；保持大小、比例、字距和光圈，不能保留任何不透明矩形背景。生成式去背景两次出现杂点，已弃用，不能作为资产接入。

## 状态、存储与实现选择

现有MaterialApp只配置dark，GRemoteColors为静态常量，因此只添加ThemeData.light不足以覆盖现有页面。实现需引入ThemeExtension/ColorScheme语义色，在展示层逐页迁移硬编码UI色，并单独保护照片内容颜色；禁止全局字符串替换色值。

- ThemePreference枚举dark/light/system，存入现有App本地设置；旧安装缺省dark，未知/损坏值回退dark，不能升级后突然跟随系统变浅。
- MaterialApp配置theme、darkTheme与themeMode；system随平台brightness变化，显式dark/light不受系统变化影响。偏好保存失败要可见且可重试，不能只改内存后假称已保存。
- 首次显示前完成轻量主题偏好加载，避免已选浅色启动先闪深色。设置只写App本地，不触发相机协议、机内设置或SD写入。
- 触感偏好与主题分开存储；修改时不清空照片草稿、LUT和旧设置。旧文档processVersion/导出参数不随主题改变。
- 透明Logo在原图轮廓基础上构建可着色蒙版，原资源保留。交互稿已使用显示时SVG alpha滤镜提取轮廓；App实现可采用等价的原生ColorFilter/蒙版资产，要求先检查实际alpha与边缘，不能以反相贴片伪装透明。
