## 页面重组与现有复用点

用户指定底栏严格为：首页、相册、相机、拍摄。

1. 首页保留连接/重试/选设备/手动 Wi-Fi/诊断、导入概况和位置记录；移除试卷台入口及营销口号。现入口在 lib/features/home/home_page.dart:79；底栏口号在 lib/app/router.dart:120。拍摄隐藏底栏与屏幕旋转逻辑硬编码旧 index=1（router.dart:91/142），重组后必须跟随新拍摄入口。
2. 相册顶层分“相册 / 相机”。当前 library_page.dart:73 已有来源切换，camera_gallery.dart:158 已有批量下载、进度、重试与格式分组。下载任务当前由 widget 持有，切 tab 卸载会丢失交互状态，需提升任务状态才能保证跨页继续。
3. 新“相册”需要持久导入集合：现 local_media_repository.dart:53 扫描系统相册 JPEG，不等于“只显示 GR 下载＋主动导入”的应用相册。默认 GR III 过滤也不能用于主动导入的其他来源。用户导入取消/无权限、重复照片、RAW 保存但不支持编辑需分别表达。
4. 现 /edit/:mediaId 已是独立全屏编辑路由；暗房当前能力为 LUT、边框、留白画幅、EXIF/信息、导出、方案和最近编辑。基础调节、曲线、暗角、统一颗粒/光晕面板不是现 editor 已完成能力，属于后续专业编辑器扩展。
5. 相机页复用现十槽 snapshot、兼容校验、差异确认、幂等 requestId、保存与激活两次事务。胶卷不可重复占槽，非空槽必须连续；已有同卷定位原槽，新卷优先第一个空槽。确认页必须显示最终实际槽位。
6. 拍摄保留实景、对焦与快门分离、曝光/程序、退出清理和恢复设置。拍摄/程序执行/原图传输期间，配置写入应继续服从现共享门禁。

## 官网胶卷库、自定义 LUT 与样片

- 现有目录可直接读取；POST /api/gr3/sd-library/export 按 model/ids/customFilms 导出 ZIP，含 FILMS.M10 和审计 manifest。不存在稳定 latest pack URL/增量清单，应新增版本化发布清单及可缓存下载资源；不能解析网页 DOM 充当 API。
- 目录以稳定 ID 为准，51 可见款不等于底层107资源。下载与缓存应绑定 model、catalogHash、rendererHash、文件 hash；官网更新不自动覆盖机内槽位，版本不兼容时保持浏览和下载，阻止写入。
- 手机 `.cube` 编辑 LUT 与相机原生 ISP 胶卷不同。现手机可持久导入 LUT；机内路径要经 M10V ISP 拟合、质量校验、bank/renderer 身份绑定，再分块上传与验证，最后单独提交槽位。当前 uploadFilm=false，旧上传暂仅0..4槽，尚未接入 native owner。
- 建议用户导入一次并收藏原 cube；作为手机编辑 LUT 可直接使用，机内版本独立呈现“转换中 / 可装入 / 转换失败”，转换近似需明确标注，不假装任意 cube 都能逐点复现。
- 官网当前参考预览是统一街景图+各胶卷 LUT，并非每卷都有实拍样片和完整介绍。需新增内容 manifest：介绍、预览类型/来源、示例图片、版本；参考预览与用户实拍分别标注。

## 专业编辑器交互路径（用户补充方向，待视觉确认）

- 相册本地照片 → 查看 → 编辑；可允许已编辑照片直接继续编辑。机内照片 → 下载/格式选择 → 相册 → 自动进入编辑，不能编辑尚未落到本地的远程占位。
- 全屏编辑器：照片主视图；基础、曲线、色彩、LUT、质感、几何六组工具。保留原图对比、撤销/重做、还原与方案；导出另存副本，原始文件不覆盖。
- 基础先含曝光、对比、高光、阴影；曲线支持 RGB/通道与控制点；LUT支持导入、选择、强度；质感含颗粒、暗角等。具体算法、色彩空间、RAW 解码范围与性能目标留待后续专业编辑器专项，不把视觉控件算作已实现能力。
- 本次底栏重构保留非破坏编辑文档、编辑历史/资源与任务的稳定入口，为未来工具添加留空间；不新增第五个暗房底栏。

## 方案供选择

- 直达工作区：相机页顶层“胶卷库 / 扩展”，十槽面板收起时不挤压库列表。适合目录浏览、找卷、频繁改设置；推荐。
- 机身总览：相机页先看当前胶卷和十槽，再进入胶卷库或扩展。机内状态更直观，但浏览和调参多一级。
