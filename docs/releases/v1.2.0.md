# GRemote 1.2.0

Android arm64，Android 8.0+，版本 `1.2.0+19`，包名 `com.izhaoo.gremote`。

## 更新

- 更新首页、相册、拍摄和相机工作区，支持深色、浅色、跟随系统外观及全局触感开关。
- 完善无损照片编辑、LUT 与曲线、历史撤销重做、裁切与边框；Android 接入驻留 GPU 预览和分块原尺寸导出。
- 同步官网胶卷资料和可移植手机色彩，「用于修图」直接进入相册选图。当前资料包含 56 卷，其中 53 款、56 个 EI 色彩变体可用于手机修图；800T、Charmera、Pixel World 暂不可用。手机色彩为官网 RGB 预览近似，不代表机内空间效果或成片完全一致。
- 整理相机扩展与 Half 设置，选择后提交并保留能力、连接状态、互斥、回执及读回校验；从已认证的机身能力选择对应胶卷目录。
- 支持经系统文件选择器导出 `FILMS.M10`；不自动写入相机，不提供整库无线替换。胶卷库仍需匹配固件，替换前应保留原文件与自定义 LUT。
