# GRemote 1.0.0

Android arm64 版本，最低 Android 8.0，版本号 `1.0.0+3`。

## 本次更新

- 优化相机图库的照片布局、多选和底部保存操作，加入平滑选择与进度动效。
- 支持 JPG、RAW（DNG）、RAW+JPG 保存；显示当前文件字节进度、已完成文件数，支持停止后续任务和失败重试。
- 修复已下载 JPG 被本机扫描规则误排除的问题；移除本机图库的“按配方”筛选。
- 首页“今日导入”显示真实保存记录，RAW/JPG 成对合并，可打开历史查看。
- “位置记录”支持开关，仅在联机拍摄页可见且应用位于前台时定位；位置关联到本地拍摄记录，不改写原始照片。
- 退出联机拍摄时停止程序、等待在途参数写入，恢复本次连接最初完整回读的可写配置并核验；失败提供重试和明确退出选项。打开协议探测也会先结束拍摄会话。
- 补充相机无线 LAN 未开启时的连接引导。

## 构建验证

- `bash scripts/build_android.sh --release`：通过。
- Flutter 静态分析无问题；328 项 Flutter 测试、36 项 Android 单元测试、1 项原生图像 CTest 全部通过。
- APK：`com.izhaoo.gremote`，`versionName=1.0.0`，`versionCode=3`，Android 8.0+，arm64-v8a。
- APK 签名验证通过；SHA-256：`545a662870542ea3594ffea8357549c09d800a40bd96def3ad5855cfba5b5025`。
