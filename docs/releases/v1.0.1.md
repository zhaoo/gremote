# GRemote 1.0.1

## 更新

- Android 发布包改用项目专用正式签名，移除 debug 签名回退。
- 新增官网：功能介绍、使用方法、发布记录。

## 升级注意

**v1.0.0 与此版本签名不同，不能直接覆盖升级。** 如果旧版本中有需要保留的作品、配方或记录，请先自行导出、备份；不要直接卸载旧安装。卸载可能丢失应用本地数据。
