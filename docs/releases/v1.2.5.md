# GRemote 1.2.5

连接兼容 M10V 相机的 Wi-Fi 后，GRemote 自动建立会话并读取机内配置。

- 移除机内胶卷页遗留的「导入配对文件」入口。
- 区分相机未连接、正在自动连接和 M10V 服务未就绪，支持重新探测连接。
- 连接失效时引导重新连接相机 Wi-Fi。
- 同步 iOS Xcode 工程的本地签名和归档准备配置，供开发者自行签名构建。

Android 8.0+，arm64-v8a，构建号 24。正式签名与 1.2.4 一致，可覆盖安装。已通过自动化检查及正式包签名校验，本版尚未真机复测。

M10V 联动需要配套固件及 SD 服务。M10V 官网开启 GRemote 连接后生成的 ZIP 包含启动脚本与服务，下载页展示文件位置和 SD 卡目录。机身首次使用需启用 SD 脚本。
